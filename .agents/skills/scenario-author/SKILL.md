# Scenario author

Use for starting scenarios, event definitions, items, recipes, buildings, region content, and narrative discoveries.

1. Read `docs/game-design.md`, milestone scope, and the current content schemas.
2. Define the player dilemma, entry conditions, crew, inventory, location constraints, hazard, reward, and recovery route.
3. Use stable content IDs and existing data-driven systems. Add engine behavior only when the concept genuinely needs a new reusable mechanic.
4. Validate references, schema versions, quantities, recipe cycles, prerequisites, and availability of tutorial-critical inputs.
5. Telegraph dangerous outcomes. Specify event cooldowns and exclusions to prevent compounded unrecoverable harm.
6. Compare starting opportunity and specialization, not just raw item counts. Label deliberately difficult origins.
7. Run a seeded start through the intended recovery point. Check at least one resource-poor or interrupted variant.

Output: validated definitions, scenario walkthrough, balance assumptions, and observed results. Lore claims do not substitute for a playable mechanical choice.
